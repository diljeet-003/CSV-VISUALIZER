### AI CSV Visualizer

Developed an interactive **AI-powered CSV data visualization application** using **Python and Streamlit** that allows users to upload datasets, automatically analyze data, perform data cleaning, and generate meaningful visualizations. The application provides **automated EDA, statistical summaries, missing-value analysis, correlation analysis, and interactive charts** to help users understand complex datasets quickly without writing code.

**Technologies:** Python, Pandas, NumPy, Streamlit, Plotly, Matplotlib, Scikit-learn
